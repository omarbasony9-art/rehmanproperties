Use a much stronger visual hierarchy.

Each internal page hero should generally contain:

1. Small section label / eyebrow
2. Large page title
3. Short supporting sentence
4. Optional CTA where appropriate
5. Subtle visual element, property photography, architectural texture, or refined layout treatment

The title needs to be the visual focus.

Example structure:

# SPACING

The current heroes are too tall for the amount of content they contain.

Fix this.

Desktop internal page hero height should generally be around:

`420px–560px`

depending on content.

Do NOT create massive 700–900px empty header sections.

On mobile, reduce padding appropriately.

The next section of the page should be partially visible without requiring excessive scrolling.

---

# TYPOGRAPHY

Make the headlines much stronger.

Desktop page title:

approximately:

`clamp(44px, 5vw, 72px)`

Use tight but elegant line-height.

Supporting copy:

approximately:

`18px–21px`

Do not make all text gray.

Use:

* White/off-white for primary titles
* Soft gray for supporting copy
* Emerald green for small labels and selective accents

Keep line lengths controlled.

Headlines should not stretch across the entire screen.

---

# ADD SUBTLE VISUAL INTEREST

The current dark backgrounds feel empty.

Add subtle visual depth WITHOUT making it flashy.

Good options:

* Property photography
* Architectural crop
* Very subtle dark image overlay
* Thin vertical/horizontal green accent
* Slight texture
* Large cropped typography
* Geometric architectural lines

Do not use fake AI-looking background graphics.

Photography should feel realistic and editorial.
